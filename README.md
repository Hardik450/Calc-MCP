# Local MCP Calculator Agent

A local AI agent built with Python, [Ollama](https://ollama.com/), and the [Model Context Protocol (MCP)](https://modelcontextprotocol.io/). The agent uses a locally running language model to understand user requests, select calculator tools, execute them through an MCP server, and generate responses using the returned results.

## Features

- **Local LLM integration:** Uses Ollama to run a language model locally.
- **MCP client:** Connects to an MCP server using standard input/output (stdio).
- **Tool discovery:** Automatically retrieves available tools from the MCP server.
- **Tool calling:** Allows the model to request calculator operations.
- **Multi-step calculations:** Supports workflows that require multiple tool calls.
- **Error handling:** Handles unknown tools and tool execution failures.
- **Conversation history:** Maintains recent messages for contextual responses.
- **No cloud API key required:** Uses a locally running Ollama instance.

## Architecture

```text
User
 |
 v
Python AI Agent (agent.py)
 |
 +------> Ollama Local LLM
 |        Selects tools and generates responses
 |
 v
MCP Client Session
 |
 v
Calculator MCP Server (calc.py)
 |
 v
Calculator Tool Execution
 |

```

Install the following:

1. Python
2. [uv](https://docs.astral.sh/uv/)
3. [Ollama](https://ollama.com/download)

Verify your installations:

```powershell
python --version
uv --version
ollama --version
```

## Setup

### 1. Clone the repository

```powershell
git clone <your-repository-url>
cd learning
```


### 2. Install dependencies

Ensure the project has been initialized with `uv` and contains the required dependencies.

```powershell
uv sync
```

If the dependencies have not yet been added, add the MCP SDK and Ollama Python library:

```powershell
uv add "mcp[cli]" ollama
```

### 3. Download a local model

The agent is configured to use `qwen3.5:2b`. Download that model if it is not already installed:

```powershell
ollama pull qwen3.5:2b
```

Check the installed models:

```powershell
ollama list
```

Make sure the model name matches the `MODEL` variable in `agent.py`.

### 4. Ensure Ollama is running

Ollama normally runs in the background on Windows. If necessary, start it from the Start menu or run:

```powershell
ollama serve
```

Keep the service running while using the agent.

## Running the Agent

From the project directory, execute:

```powershell
uv run python agent.py
```

The agent starts the calculator MCP server automatically using its stdio configuration. You do not need to launch `calc.py` in another terminal for this setup.

Once connected, you can enter natural-language questions.

Example:

```text
You: What is 25 multiplied by 4?

Assistant: 25 multiplied by 4 equals 100.

You: Add 150 and 250, then divide the result by 4.

Assistant: The final result is 100.

You: exit

Goodbye!
```


## How It Works

1. **Initialize the agent:** `agent.py` creates an asynchronous Ollama client.
2. **Start the MCP server:** The client launches `calc.py` as a subprocess using `uv`.
3. **Initialize the MCP session:** The client and server establish communication over stdio.
4. **Discover tools:** The client calls `session.list_tools()` to retrieve available tool definitions.
5. **Convert tool definitions:** MCP tool schemas are converted into Ollama's function-tool format.
6. **Send the user request:** The question, conversation history, and available tools are sent to the local model.
7. **Process tool calls:** If the model requests a tool, the agent extracts its name and arguments.
8. **Execute the tool:** The agent invokes `session.call_tool()` to ask the MCP server to execute the operation.
9. **Return the result:** The tool result is added to the conversation history.
10. **Generate the final response:** The model uses the result to produce an answer for the user.

## Testing the MCP Server

To inspect the calculator server independently, run:

```powershell
uv run mcp dev calc.py
```

MCP Inspector allows you to connect to the server, discover its tools, and test them without involving the Ollama agent.

**Note:** `mcp dev` is intended for inspecting the MCP server. Run the AI client with `uv run python agent.py`.

## Configuration

The following settings are defined in `agent.py`:

| Variable | Purpose |
|---|---|
| `PROJECT_DIR` | Determines the directory containing the agent. |
| `MODEL` | Specifies the Ollama model to use. |
| `MAX_TOOL_ROUNDS` | Limits the number of model-response rounds for a question. |

## Troubleshooting

### Ollama connection error

Ensure Ollama is installed and running:

```powershell
ollama list
```

If necessary, start the Ollama service and retry.

### Model not found

Download the configured model:

```powershell
ollama pull qwen3.5:2b
```


### MCP server fails to start

Verify that `calc.py` exists in the project directory and that the required dependencies are installed:

```powershell
uv sync
```

You can also inspect the server independently:

```powershell
uv run mcp dev calc.py
```
